Asset Tap

Generate 3D models from text prompts. Text → AI image → 3D model → FBX export. Dynamic API provider configurations let you plug in any supported backend and swap between models on the fly. Built-in 3D viewer, reusable prompt templates, and a library to organize everything you generate. Open source, built with Rust, available on macOS, Windows, and Linux — GUI and CLI.
